Welcome to HorizonRobotics RobotLab
====================================================


About
--------------------

Welcome to the Robot Lab of Horizon Robotics. Our mission is to build cutting edge and fully open-sourced Embodied AI Algorithms and infrastructures.
Together with Horizon's computing platform, we wish to empower the future of robots with all types of embodiment.

RoboOrchard
^^^^^^^^^^^^^^

.. list-table::
   :widths: 20 80
   :class: publication-table

   * - .. image:: _static/projects/robo_orchard/logo.png
          :class: publication-thumbnail
          :alt: RoboOrchardLab Logo
          :target: _static/projects/robo_orchard/logo.png

     - **RoboOrchard** is a collection of tools and frameworks designed to streamline the entire process of robotics research and development,
       from simulation to real-world application.

* **RoboOrchardBuild**: A set of tools designed to simplify the build process for the RoboOrchard project.

  `Code <https://github.com/HorizonRobotics/robo_orchard_build>`__ | `Pypi <https://pypi.org/project/robo-orchard-build>`__

* **RoboOrchardCore**: The core package of the project RoboOrchard, which provides the basic infrastructure for the framework, such as configuration management, data structure, environment abstraction, etc.

  `Code <https://github.com/HorizonRobotics/robo_orchard_core>`__ | `Pypi <https://pypi.org/project/robo-orchard-core>`__

* **RoboOrchardSchemas**: A library of data models for the RoboOrchard project.

  `Code <https://github.com/HorizonRobotics/robo_orchard_schemas>`__ | `Pypi <https://pypi.org/project/robo-orchard-schemas>`__

* **RoboOrchardLab**: Training and evaluating embodied AI algorithm

  `Code <https://github.com/HorizonRobotics/robo_orchard_lab>`__ | `Docs <https://horizonrobotics.github.io/robot_lab/robo_orchard/lab/master/index.html>`__ | `Pypi <https://pypi.org/project/robo-orchard-lab>`__ | `Model Zoo <https://huggingface.co/collections/HorizonRobotics/robo-orchard-lab-682aaf611e571caf8d62cb51>`__

* **RoboOrchardGraspLabel**: A set of tools to generate grasp labels for objects

  `Code <https://github.com/HorizonRobotics/robo_orchard_grasp_label>`__
