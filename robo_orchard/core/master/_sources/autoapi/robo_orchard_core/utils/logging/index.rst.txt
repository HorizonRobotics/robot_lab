.. py:class:: LoggerManager(format: str = DEFAULT_LOG_FORMAT, level: int = logging.INFO, handlers: typing_extensions.Optional[list[logging.Handler]] = None)

   Bases: :py:obj:`_Singleton`


   A logger manager that manages the logger.

   This class is a singleton class that manages the logger. It provides
   methods to get the logger and its child logger. You can use the logger
   manager to handle all loggers in the project.

   Example:

   .. code-block:: python

       # To get a child logger
       from robo_orchard_core.utils.logging import LoggerManager

       logger = LoggerManager().get_child(__name__)


   :param format: The format of the log. Defaults to
                  DEFAULT_LOG_FORMAT.
   :type format: str, optional
   :param level: The level of the log. Defaults to logging.INFO.
   :type level: int, optional
   :param handlers: The handlers of
                    the log. Defaults to None.
   :type handlers: Optional[list[logging.Handler]], optional
