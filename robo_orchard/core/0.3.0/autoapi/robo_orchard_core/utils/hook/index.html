Bases: Generic[T]

Context manager for executing hooks with a specific set of arguments.

This class is used to manage the lifecycle of hooks, ensuring that the appropriate hook methods are called at the right times. It also provides a way to pass arguments to the hooks in a structured manner.

class robo_orchard_core.utils.hook.HookContextFromCallable(name: str | None = None, before: Callable[[T], None] | None = None, after: Callable[[T], None] | None = None)[source]¶

Bases: HookContext[T]

A hook context that is created from a callable.

This class is used to create a hook context from a callable that takes a single argument and returns a value. The callable is called in the before method and the returned value is passed to the after method.

Parameters:

  • name (str | None) – The name of the hook context. If not provided, it will be set to an empty string, which indicates that the hook context is anonymous. Defaults to None.

  • before (Callable[[T], None] | None) – The callable to be used as the before method. If not provided, it will be set to None. Defaults to None.

  • after (Callable[[T], None] | None) – The callable to be used as the after method. If not provided, it will be set to None. Defaults to None.

class robo_orchard_core.utils.hook.HookContextChannel(name: str)[source]¶

Bases: Generic[T]

A channel for managing hook context.

The hook contexts are registered and executed in a specific order when the begin method is called. This class provides a way to register and unregister hook context handlers.
