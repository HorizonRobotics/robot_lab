      Roll out the environment for a number of steps.

      This function is used to run the environment for a number of steps
      and return the results of each step.

      :param max_steps: The maximum number of steps to roll out the
                        environment.
      :type max_steps: int
      :param init_obs: The initial observations to start the rollout
                       from.
      :type init_obs: Any
      :param policy: The policy to use for
                     taking actions in the environment. If None, random actions
                     will be taken. Defaults to None.
      :type policy: PolicyMixin | None, optional
      :param env_step_callback: A callback function that takes in the current action and the
                                result of the step. This can be used to log information or
                                perform other operations after each step. Defaults to None.
      :type env_step_callback: Callable[[Any, Any], None] | None, optional
      :param terminal_condition: A function that takes in the result of a step and returns
                                 whether to terminate the rollout. If None, the rollout will
                                 continue until max_steps is reached. Defaults to None.
      :type terminal_condition: Callable[[Any], bool] | None, optional
      :param keep_last_results: If > 0, only keep the last
                                `keep_last_results` results. This is useful for long rollouts
                                where only the last few results are needed. Defaults to -1,
      :type keep_last_results: int, optional

      :returns:

                An instance of `EnvRolloutReturn` containing
                    the actions taken and the results from each step of the
                    environment.
      :rtype: EnvRolloutReturn

   .. py:property:: num_envs
      :type: int


      The number of instances of the environment that are running.

      For example, if the environment is a single instance, then this
      should return 1. This is the case for most classical environments.

      In the case of reforcement learning, usually a vectorized environment
      is used to run multiple instances of the environment in parallel to
      speed up the training process. In this case, this function should
      return the number of instances of the environment that are running.

      The number of instances of the environment is used in other parts of
      the code to manage the environment.

   Abstract base class for generic types.

   A generic type is typically declared by inheriting from
   this class parameterized with one or more type variables.
   For example, a generic mapping type might be defined as::

     class Mapping(Generic[KT, VT]):
         def __getitem__(self, key: KT) -> VT:
             ...
         # Etc.

   This class can then be used as follows::

     def lookup_name(mapping: Mapping[KT, VT], key: KT, default: VT) -> VT:
         try:
             return mapping[key]
         except KeyError:
             return default
