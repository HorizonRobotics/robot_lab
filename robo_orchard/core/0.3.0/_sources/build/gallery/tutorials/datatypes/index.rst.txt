Data Types
================

Welcome to the tutorials for the core data types of ``robo_orchard_core``. These
data structures form the backbone of the library, providing standardized and
batch-processed representations for essential robotics concepts.

Mastery of these objects is the first step toward building efficient and
robust applications with the framework.
