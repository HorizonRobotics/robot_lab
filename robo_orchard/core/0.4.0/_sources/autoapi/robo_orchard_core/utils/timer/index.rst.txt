.. py:class:: Timer(name_or_func: Any = None, unit: str = 'auto', logger: logging.Logger = logger)

   Bases: :py:obj:`object`


   Timer class for timing function execution.

   Modify from https://github.com/LucienShui/timer .


   :param name_or_func: name of function, or function itself,
                        user should not care about this parameter. Defaults to None.
   :type name_or_func: Any
   :param unit: time's unit, should be one of 's', 'ms' or 'auto'.
                Defaults to 'auto'.
   :type unit: str
   :param logger: logger object. Defaults to logger.
   :type logger: logging.Logger

   Example:
   >>> with Timer():
   ...     print("hello")
   cost 0.001 s

   >>> @Timer()
   ... def foo():
   ...     print("hello")
   >>> foo()
   cost 0.001 s

   >>> @Timer("foo")
   ... def bar():
   ...     print("hello")
   >>> bar()
   cost 0.001 s
