.. py:class:: CodecMixin

   CodecMixin is an API for encoding and decoding data.

   The codec concept is suitable for `Tokenizer`, `VAE`, and other models
   that transform data into a different representation and back.



   .. py:method:: encode(data: torch.Tensor, *args, **kwargs) -> torch.Tensor
      :abstractmethod:


      Encode data.



   .. py:method:: decode(data: torch.Tensor, *args, **kwargs) -> torch.Tensor
      :abstractmethod:


      Decode data.
