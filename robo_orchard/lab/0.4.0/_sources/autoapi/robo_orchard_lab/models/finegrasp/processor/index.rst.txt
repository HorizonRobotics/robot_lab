.. py:class:: GraspInput

   Input data for FineGraspProcessor.

   :param rgb_image: RGB image of shape (H, W, 3),
   :type rgb_image: str | np.ndarray
   :param depth_image: Depth image of shape (H, W),
   :type depth_image: str | np.ndarray
   :param intrinsic_matrix: Camera intrinsic matrix of shape (3, 3),
   :type intrinsic_matrix: str | np.ndarray
   :param points: Point cloud of shape (N, 3). If provided,
                  depth_image will be ignored.
   :type points: np.ndarray | None
   :param depth_scale: Scale factor to convert raw depth values to
                       metric units. For example, if the depth map values are in
                       millimeters and you want meters, set `depth_scale=1000.0`.
   :type depth_scale: float
   :param grasp_workspace: Workspace limits [xmin, xmax, ymin,
                           ymax, zmin, zmax].
   :type grasp_workspace: List[float]
   :param num_sample_points: Number of points to sample from the point
                             cloud.
   :type num_sample_points: int

   .. rubric:: Example

   >>> from robo_orchard_lab.models.finegrasp.processor import GraspInput
   >>> import numpy as np
   >>> rgb_image = np.random.rand(480, 640, 3).astype(np.float32)
   >>> depth_image = (
   ...     np.random.rand(480, 640).astype(np.float32) * 1000
   ... )  # in mm
   >>> intrinsic_matrix = np.array(
   ...     [[600, 0, 320], [0, 600, 240], [0, 0, 1]], dtype=np.float32
   ... )
   >>> depth_scale = 1000.0
   >>> grasp_workspace = [-1, 1, -1, 1, 0.0, 2.0]
   >>> input_data = GraspInput(
   ...     rgb_image=rgb_image,
   ...     depth_image=depth_image,
   ...     depth_scale=depth_scale,
   ...     intrinsic_matrix=intrinsic_matrix,
   ...     grasp_workspace=grasp_workspace,
   ... )
   >>> print(input_data.grasp_workspace)
   [-1, 1, -1, 1, 0.0, 2.0]
   >>> print(input_data.rgb_image.shape)
   (480, 640, 3)
   >>> print(input_data.depth_image.shape)
   (480, 640)
   >>> print(input_data.intrinsic_matrix.shape)
   (3, 3)

.. py:class:: FineGraspProcessor(cfg: FineGraspProcessorCfg)

   Bases: :py:obj:`robo_orchard_lab.inference.processor.ProcessorMixin`


   An abstract base class for data processing modules.

   This class defines a standard interface for data processors, which are
   responsible for encapsulating the pre-processing and post-processing logic
   required for a model. Subclasses must implement the `pre_process` method.

   The primary role of a processor is to convert raw, user-provided data into
   a format suitable for model consumption (pre-processing) and to convert the
   model's raw output into a user-friendly, understandable format
   (post-processing).


   .. py:attribute:: cfg
      :type:  FineGraspProcessorCfg


   .. py:method:: get_normal(point_cloud)


   .. py:method:: pre_process(input_data: GraspInput, device: str = 'cuda') -> Dict[str, torch.Tensor]

      Transforms raw data into a model-ready format.

      Subclasses must implement this method to handle the conversion of
      user-provided input into the specific format expected by the model.

      :param data: The raw input data.

      :returns: The processed data, ready to be collated into a batch.



   .. py:method:: post_process(model_outputs, input_data) -> GraspOutput

      Transforms model output into a user-friendly format.

      This method can be overridden by subclasses to convert the raw tensor
      outputs from the model into a more structured or interpretable format,
      such as dictionaries with meaningful keys, text, or image objects.

      By default, it performs an identity mapping, returning the model
      outputs as is.

      :param model_outputs: The raw output from the model's forward pass.
      :param model_input: The transformed batch as model input. For some
                          processors, this may be needed for context during
                          post-processing.

      :returns: The post-processed, user-friendly output.
