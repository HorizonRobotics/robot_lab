.. py:function:: create_merged_dataset(datasets: list[robo_orchard_lab.dataset.robot.dataset.RODataset], cache_dir: str, db_driver: str = 'duckdb', cache_meta_idx_mappings_in_memory: bool = False) -> robo_orchard_lab.dataset.robot.dataset.RODataset

   Merge multiple RODatasets into a single RODataset.

   :param datasets: The list of RODatasets to merge.
   :type datasets: list[RODataset]
   :param cache_dir: The directory to store the merged meta database
                     and temporary files.
                     Note that this directory should not be deleted until the merged
                     dataset is no longer needed, as the merged dataset relies on
                     the meta database stored in this directory.
   :type cache_dir: str
   :param db_driver: The database driver to use for the
                     merged meta database. Defaults to "duckdb".
   :type db_driver: str, optional
   :param cache_meta_idx_mappings_in_memory: Whether to cache
                                             the source to destination index mappings in memory.
                                             If False, the mappings will be stored in a memory mapped temporary
                                             files in `cache_dir`, which use dense numpy arrays.
                                             If True, the mappings will be stored in memory using dicts,
                                             which may use more memory but may be faster for sources with
                                             sparse indices. Defaults to False.
   :type cache_meta_idx_mappings_in_memory: bool, optional

   :returns: The merged RODataset.
   :rtype: RODataset

   Merge multiple RODatasets and save to disk.

   :param max_shard_size: The maximum size of
                          each shard. Defaults to "8000MB". This can be a string
                          (e.g., "8000MB") or an integer (e.g., 8000 * 1024 * 1024
                          for 8000MB).
   :type max_shard_size: str | int , optional
   :param num_shards: The number of shards to create.
                      Number of shards to write. By default the number of shards
                      depends on `max_shard_size` and `num_proc`.
   :type num_shards: int | None, optional
   :param num_proc: The number of processes to use
                    for saving the dataset. Defaults to None.
   :type num_proc: int | None, optional
   :param storage_options: Additional Key/value pairs
                           to be passed on to the file-system backend, if any. Defaults
                           to None.
   :type storage_options: dict | None, optional
   :param batch_size: The batch size to use when
                      saving the dataset. If None, the default batch size from
                      Hugging Face Datasets will be used. Defaults to None.
   :type batch_size: int | None, optional
