      Forward Function of MultiScaleDeformAttention.

      :param query: Query of Transformer with shape
                    (num_query, bs, embed_dims).
      :type query: Tensor
      :param key: The key tensor with shape
                  `(num_key, bs, embed_dims)`.
      :type key: Tensor
      :param value: The value tensor with shape
                    `(num_key, bs, embed_dims)`.
      :type value: Tensor
      :param identity: The tensor used for addition, with the
                       same shape as `query`. Default None. If None,
                       `query` will be used.
      :type identity: Tensor
      :param query_pos: The positional encoding for `query`.
                        Default: None.
      :type query_pos: Tensor
      :param key_padding_mask: ByteTensor for `query`, with
                               shape [bs, num_key].
      :type key_padding_mask: Tensor
      :param reference_points: The normalized reference
                               points with shape (bs, num_query, num_levels, 2),
                               all elements is range in [0, 1], top-left (0,0),
                               bottom-right (1, 1), including padding area.
                               or (N, Length_{query}, num_levels, 4), add
                               additional two dimensions is (w, h) to
                               form reference boxes.
      :type reference_points: Tensor
      :param spatial_shapes: Spatial shape of features in
                             different levels. With shape (num_levels, 2),
                             last dimension represents (h, w).
      :type spatial_shapes: Tensor
      :param level_start_index: The start index of each level.
                                A tensor has shape ``(num_levels, )`` and can be represented
                                as [0, h_0*w_0, h_0*w_0+h_1*w_1, ...].
      :type level_start_index: Tensor

      :returns: forwarded results with shape [num_query, bs, embed_dims].
      :rtype: Tensor



.. py:class:: SinePositionalEncoding(num_feats: int, temperature: int = 10000, normalize: bool = False, scale: float = 2 * math.pi, eps: float = 1e-06, offset: float = 0.0)

   Bases: :py:obj:`torch.nn.Module`


   Position encoding with sine and cosine functions.

   See `End-to-End Object Detection with Transformers
   <https://arxiv.org/pdf/2005.12872>`_ for details.

   :param num_feats: The feature dimension for each position
                     along x-axis or y-axis. Note the final returned dimension
                     for each position is 2 times of this value.
   :type num_feats: int
   :param temperature: The temperature used for scaling
                       the position embedding. Defaults to 10000.
   :type temperature: int, optional
   :param normalize: Whether to normalize the position
                     embedding. Defaults to False.
   :type normalize: bool, optional
   :param scale: A scale factor that scales the position
                 embedding. The scale will be used only when `normalize` is True.
                 Defaults to 2*pi.
   :type scale: float, optional
   :param eps: A value added to the denominator for
               numerical stability. Defaults to 1e-6.
   :type eps: float, optional
   :param offset: offset add to embed when do the normalization.
                  Defaults to 0.
   :type offset: float


   .. py:attribute:: num_feats


   .. py:attribute:: temperature
      :value: 10000



   .. py:attribute:: normalize
      :value: False



   .. py:attribute:: scale
      :value: 6.283185307179586



   .. py:attribute:: eps
      :value: 1e-06



   .. py:attribute:: offset
      :value: 0.0



   .. py:method:: forward(mask: torch.Tensor, input: Optional[torch.Tensor] = None) -> torch.Tensor

      Forward function for `SinePositionalEncoding`.

      :param mask: ByteTensor mask. Non-zero values representing
                   ignored positions, while zero values means valid positions
                   for this image. Shape [bs, h, w].
      :type mask: Tensor

                    Shape [bs, c, h, w]
      :type input: Tensor, optional

      :returns:

                Returned position embedding with shape
                    [bs, num_feats*2, h, w].

.. py:class:: SingleScaleBiAttentionBlock(v_dim: int, l_dim: int, embed_dim: int, num_heads: int, dropout: float = 0.1, init_values: float = 0.0001)

   Bases: :py:obj:`torch.nn.Module`


   BiAttentionBlock Module.

   First, multi-level visual features are concat; Then the concat visual
   feature and lang feature are fused by attention; Finally the newly visual
   feature are split into multi levels.

   :param v_dim: The dimension of the visual features.
   :type v_dim: int
   :param l_dim: The dimension of the language feature.
   :type l_dim: int
   :param embed_dim: The embedding dimension for the attention operation.
   :type embed_dim: int
   :param num_heads: The number of attention heads.
   :type num_heads: int
   :param dropout: The dropout probability. Defaults to 0.1.
   :type dropout: float, optional
   :param init_values: The initial value for the scaling parameter.
                       Defaults to 1e-4.
   :type init_values: float, optional
