.. py:function:: get_text_sine_pos_embed(pos_tensor: torch.Tensor, num_pos_feats: int = 128, temperature: int = 10000, exchange_xy: bool = True)

   Generate sine position embedding from a position tensor.

   :param pos_tensor: shape: [..., n].
   :type pos_tensor: torch.Tensor
   :param num_pos_feats: projected shape for each float in the tensor.
   :type num_pos_feats: int
   :param temperature: temperature in the sine/cosine function.
   :type temperature: int
   :param exchange_xy: exchange pos x and pos y. For example,
                       input tensor is [x,y], the results will be [pos(y), pos(x)].
                       Defaults to True.
   :type exchange_xy: bool, optional

   :returns: shape: [..., n*num_pos_feats].
   :rtype: pos_embed (torch.Tensor)


.. py:function:: get_encoder_reference_points(spatial_shapes: torch.Tensor, valid_ratios: torch.Tensor, device: Union[torch.device, str]) -> torch.Tensor

   Get the reference points used in encoder.

   :param spatial_shapes: Spatial shapes of features in all levels,
                          has shape (num_levels, 2), last dimension represents (h, w).
   :type spatial_shapes: Tensor
   :param valid_ratios: The ratios of the valid width and the valid
                        height relative to the width and the height of features in all
                        levels, has shape (bs, num_levels, 2).
   :type valid_ratios: Tensor
   :param device (obj: `device` or str): The device acquired by the
                       `reference_points`.

   :returns: Reference points used in decoder, has shape (bs, length,
             num_levels, 2).
   :rtype: Tensor

   Base class for all neural network modules.

   Your models should also subclass this class.

   Modules can also contain other Modules, allowing them to be nested in
   a tree structure. You can assign the submodules as regular attributes::

       import torch.nn as nn
       import torch.nn.functional as F

       class Model(nn.Module):
           def __init__(self) -> None:
               super().__init__()
               self.conv1 = nn.Conv2d(1, 20, 5)
               self.conv2 = nn.Conv2d(20, 20, 5)

           def forward(self, x):
               x = F.relu(self.conv1(x))
               return F.relu(self.conv2(x))

   Submodules assigned in this way will be registered, and will also have their
   parameters converted when you call :meth:`to`, etc.

   .. note::

       must be made before assignment on the child.
