.. py:function:: create_engine(url: sqlalchemy.URL, readonly: bool = False, json_serializer: Callable[[Any], str] = lambda obj: json.dumps(obj, sort_keys=True, ensure_ascii=True), auto_upgrade: bool = True, **kwargs)

   Create a database engine.

   This method is a wrapper of :py:func:`sqlalchemy.create_engine` with
   additional support for readonly mode, and default JSON serializer.

   See :py:func:`sqlalchemy.create_engine` for more details.

   :param url: The database URL.
   :type url: URL
   :param readonly: Whether to create a readonly engine.
                    Defaults to False.
   :type readonly: bool, optional
   :param json_serializer: The JSON serializer
                           for the engine. Defaults to
                           `lambda obj: json.dumps(obj, sort_keys=True, ensure_ascii=True).`
   :type json_serializer: Callable[[Any], str], optional
   :param auto_upgrade: Whether to automatically upgrade the
                        database to the latest version when reading.
                        Defaults to True.
   :type auto_upgrade: bool, optional
   :param \*\*kwargs: Additional keyword arguments for
                      :py:func:`sqlalchemy.create_engine`.

   :returns: The database engine.
   :rtype: Engine
