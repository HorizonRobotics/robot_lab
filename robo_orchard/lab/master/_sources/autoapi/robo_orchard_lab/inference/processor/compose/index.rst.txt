.. py:class:: ComposeProcessor(cfg: ComposeProcessorCfg)

   Bases: :py:obj:`robo_orchard_lab.inference.processor.mixin.ProcessorMixin`


   A processor that chains multiple processors together.

   This processor acts as a container to apply a sequence of other processors
   serially. It allows for building complex data processing pipelines from
   smaller, modular components.


   .. py:attribute:: cfg
      :type:  ComposeProcessorCfg


   .. py:attribute:: processors
      :type:  list[robo_orchard_lab.inference.processor.mixin.ProcessorMixin]


   .. py:method:: pre_process(data)

      Applies the `pre_process` method of each processor in sequence.

      The output of one processor becomes the input to the next.

      :param data: The initial raw input data.

      :returns: The data after being transformed by all processors in the sequence.



   .. py:method:: post_process(model_outputs, model_input)

      Transforms model output into a user-friendly format.

      This method can be overridden by subclasses to convert the raw tensor
      outputs from the model into a more structured or interpretable format,
      such as dictionaries with meaningful keys, text, or image objects.

      By default, it performs an identity mapping, returning the model
      outputs as is.

      :param model_outputs: The raw output from the model's forward pass.
      :param model_input: The transformed batch as model input. For some
                          processors, this may be needed for context during
                          post-processing.

      :returns: The post-processed, user-friendly output.
